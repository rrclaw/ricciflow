# NPC 素材：本地例程产出，桥只读

桥是纯 stdlib Python，**上不了网**。所以「最近公开发言」这一路必须由本地 Claude 跑：
搜索 → 蒸馏 → 落盘成 `bridge/npc/<id>.json`，桥读文件，网站呈现。

## 怎么跑

在本地 Claude 会话里，对 `bridge/npc.py` 的 `ROSTER` 逐个角色：

1. WebSearch 该人物**最近 30 天**的公开发言（业绩会、访谈、大会演讲、官方博客）
2. 每条压缩成一句话，**只允许压缩原话，不允许推演「他会怎么说」**
3. 写成下面的结构，落到 `bridge/npc/<id>.json`

按纪律，这个例程注册在**定时任务 UI**，不走 launchd。

## 结构

```json
{
  "id": "huang",
  "refreshed_at": "2026-08-04",
  "quotes": [
    {
      "date": "2026-07-28",
      "text": "原话压缩成的一句，不改立场不加料",
      "kind": "公开发言",
      "topic": "算力需求",
      "url": "https://…"
    }
  ]
}
```

## 硬规则

- **没有 `url` 或没有 `date` 的条目会被桥直接丢弃。** 没出处的引述就是编的。
- 桥按日期算时效：≤30 天进对话池，31–90 天标「稍旧」，>90 天只进历史折叠区。
- 真名会在桥那侧换成化名再给前端。这里写原文即可，不用自己脱敏。
- 全部素材都过 90 天时，NPC 显示「他最近没公开表态」——**不许拿旧话充数**。
